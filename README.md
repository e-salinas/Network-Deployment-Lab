## Network Deployment & Troubleshooting Lab

## Project Overview

This project simulates the deployment of a segmented small-enterprise network in Cisco Packet Tracer. The network was designed with separate Admin, Operations, IT, and Management VLANs, with inter-VLAN routing, DHCP, internal DNS, secure SSH management, and an ASA firewall providing PAT and connectivity to a simulated ISP and external network.

The project also focused on practical network troubleshooting. During deployment, I diagnosed and corrected Layer 2 trunking and access-port issues, DHCP configuration errors, routing problems, firewall configuration issues, and failed ICMP traffic caused by a missing inspection policy. Connectivity and services were validated using Cisco IOS/ASA diagnostic commands and end-to-end testing.
